# 今日の献立

HTML / CSS / JavaScript だけで動く、シンプルな料理レシピ管理ツールです。

## 使い方
`index.html` をブラウザで開くだけで使えます（サーバー・インストール不要）。

## 機能
- レシピ一覧（料理名・1人分カロリー・人数・材料数）
- 分類タブ（すべて／主菜／副菜／汁物／ごはん・麺／その他）で絞り込み。件数表示つき、選んだタブは次回も保持
- 料理名・材料名での検索（タブと組み合わせ可）
- レシピ詳細：材料と分量、栄養素、作り方
- 画面上端に固定された人数バー（1人〜4人のボタン、または数字入力）で分量・栄養素・合計カロリーを自動計算。選んだ人数は他のレシピにも適用され、次回も保持
- 栄養素：エネルギー・たんぱく質・脂質・炭水化物・食塩相当量（1人分）＋ PFCバランス
- 材料をタップすると栄養の解説を表示（主な栄養素・解説・このレシピでの量の栄養価・100gあたりの値・調理のポイント）
- 栄養素（たんぱく質・脂質など）をタップすると「〇〇とは」の詳しい解説を表示（体での働き・不足／とりすぎの影響・1日の目安・多く含む食品・1日の基準値に対する割合・レシピ内で多く含む材料）
- レシピの追加・編集・削除（分類も選択可、材料・手順の行は自由に増減）
- サンプルとして和食20品を収録（生姜焼き・さばの味噌煮・筑前煮・だし巻き卵・豚汁・茶碗蒸し など）
- データはブラウザの localStorage に保存
- スマートフォン対応・ダークモード対応

## ファイル構成
| ファイル | 内容 |
|---|---|
| `index.html` | 画面構成（一覧・詳細・編集） |
| `style.css` | デザイン・レスポンシブ対応 |
| `app.js` | データ管理・画面切り替え・計算 |
| `samples.js` | サンプルレシピ（和食20品を含む24品） |
| `nutrients.js` | 栄養素の解説データ（約40種類） |
| `ingredients.js` | 材料の栄養データ（約60品目、100gあたりの目安） |

## メモ
- 栄養素は「レシピ全体の合計値」を入力します。1人分は人数で割って表示します。
- 分量を空欄にすると「適量」と表示されます。
- サンプルデータに戻したい場合は、ブラウザの開発者ツールで localStorage の `ouchi-recipes-v1` を削除してください。
- 材料の栄養データは日本食品標準成分表（八訂）をもとにした目安です。`ingredients.js` に項目を追加すると解説できる材料を増やせます。
- 和食20品の栄養素は `ingredients.js` の材料データから計算した目安です（煮汁やつゆは全量を口にした場合の値）。
